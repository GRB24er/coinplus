# Architecture Decision Records

This directory captures significant, hard-to-reverse architecture decisions and the
reasoning behind them, so future contributors understand _why_ the system looks the way
it does — not just _what_ it does.

Each record is numbered and immutable once **Accepted**. To change a past decision, add a
new record that supersedes it rather than editing history.

Status values: `Proposed` → `Accepted` / `Rejected` → `Superseded by NNNN`.
